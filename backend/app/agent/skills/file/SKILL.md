# file

当用户需要**读取、写入、列出、删除、创建目录或移动/重命名**工作区沙箱内的本地文件时，必须调用本技能提供的工具，**不要**编造文件内容或目录结构。

## 路径规则

- 一律使用**相对于工作区沙箱根**的路径，例如 `notes/readme.md`、`reports/2026/`。
- 不要使用 `..`、绝对路径（`/etc/...`）或 `~`。
- **禁止**使用操作系统保留目录名作为路径段（如 `etc`、`proc`、`Windows`、`System32`、`Program Files` 等，不区分大小写）。
- 不确定路径时，先调用 `list_dir` 再操作。

## 工具

| 工具 | 用途 |
|------|------|
| `list_dir` | 列出目录下的直接子项（不递归） |
| `read_file` | 读取 UTF-8 文本文件 |
| `write_file` | 创建或覆盖写入 UTF-8 文本 |
| `delete_path` | 删除文件或目录（非空目录需 `recursive: true`） |
| `mkdir` | 创建目录 |
| `move_path` | 移动或重命名（目标父目录须已存在） |

## 限制

- 仅支持 UTF-8 文本；单文件大小受服务器配置限制。
- 二进制文件、超大文件应告知用户无法通过本技能处理。
