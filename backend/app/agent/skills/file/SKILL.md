# file

工作区**沙箱**内的文件与目录操作（非用户本机磁盘）。路径均为相对沙箱根目录，禁止 `..` 与绝对路径。

**能力范围**：列出目录、读取文本、**创建目录**、**创建/覆盖写入文件**、删除、销毁、移动/重命名等与文件操作相关的功能。仅支持 UTF-8 文本，不支持二进制。

## 何时使用

**Planner 必选本 skill（`skill_id=file`）**：用户要在**沙箱/工作区**内对文件或目录进行任何操作，包括但不限于：

- **浏览**：列出根目录或某目录下的文件与子目录（「当前目录有什么」「列出 notes」）
- **读取**：查看、打开、读取某文件内容
- **写入**：保存、覆盖、追加式改写（用 `write_file` 写入完整内容）
- **创建文件**：新建空文件或带内容的文件（`write_file`，父目录不存在时默认自动创建）
- **创建目录**：新建文件夹（`mkdir`，默认 `parents=true` 可建多级目录）
- **删除（销毁）**：删除文件或目录（非空目录需 `recursive=true`）
- **移动/重命名**：`move_path`（`src` → `dest`）

禁止使用 `general`（general 无文件工具，会错误建议用户在本机执行 `ls`/`dir` 或手动建文件）。

**子 Agent 执行**：进入本 skill 后**必须调用工具**完成操作，不得编造目录结构或文件内容。

- 「当前目录/根目录」：`path=""` 表示沙箱根
- **建目录**：`mkdir`；若同时要写文件且路径含新目录，也可用 `write_file`（`create_parents` 默认 true）
- **建文件 / 写内容**：`write_file(path, content)`，不存在则创建，存在则覆盖
- 操作后可用 `list_dir` 或 `read_file` 核对结果，再根据工具返回的 JSON 向用户说明

## 工具选用

| 用户意图 | 工具 | 要点 |
|----------|------|------|
| 看某目录里有什么 | `list_dir` | `path` 默认 `""` 为沙箱根 |
| 读文件内容 | `read_file` | 超限返回 `too_large` |
| **新建或覆盖文件** | `write_file` | `content` 为全文；`create_parents` 默认 true |
| **新建目录** | `mkdir` | `parents` 默认 true，可一次建多级 |
| 删文件或目录 | `delete_path` | 非空目录需 `recursive=true` |
| 移动/改名 | `move_path` | `src`、`dest` 均为沙箱内相对路径 |

## 工具一览

| 工具 | 说明 |
|------|------|
| `list_dir` | 列出目录直接子项（`path` 默认 `""` 为沙箱根） |
| `read_file` | 读取 UTF-8 文本（超限返回 `too_large`） |
| `write_file` | **创建或覆盖**写入 UTF-8 文本（`create_parents` 默认 true，自动建父目录） |
| `mkdir` | **创建目录**（`parents` 默认 true，可建多级；已存在则成功） |
| `delete_path` | 删除文件或目录（非空目录需 `recursive=true`） |
| `move_path` | 移动或重命名（`src` → `dest`） |

## 返回格式

所有工具返回 JSON 字符串：成功含 `"ok": true`；失败含 `"ok": false`, `"error"`, `"code"`。
